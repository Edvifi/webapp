# Edvifi Timeline — Web (React + Vite)

The web version of the college application timeline. Same visual design as the mobile app, adapted for desktop with side-panel milestone cards and scroll navigation.

## Setup

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion (animations)
- SVG path rendering (same Catmull-Rom geometry as the mobile app)
