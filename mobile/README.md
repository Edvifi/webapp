# Edvifi Timeline — Mobile (React Native / Expo)

The original mobile prototype. A step-by-step college application timeline with a snake SVG path, animated milestones, and year-specific particle backgrounds.

## Setup

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go (iOS/Android) or press `i` / `a` to open in a simulator.

## Stack

- React Native + Expo SDK 51
- React Native Reanimated (animations)
- React Native Gesture Handler (tap/swipe)
- React Native SVG (path rendering)
